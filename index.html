Sobre o projeto

Disciplina

Avaliação prática individual de Desenvolvimento Web da UNEMAT, com o professor Ivan Luiz Pedroso Pires.

Tecnologias

HTML5 semântico, CSS, JavaScript com módulos ES, Fetch API para as requisições AJAX e Bootstrap 5.3 para layout e componentes.

Dados e imagens

Os dados ficam em arquivos JSON locais: um para a listagem e um por livro para os detalhes. As capas são ilustrações próprias, não são as capas oficiais.
